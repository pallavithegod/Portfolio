# Pallavi Jain — Portfolio

Personal portfolio for Pallavi Jain, a Computer Science and Engineering undergraduate and full-stack developer working on AI agents, backend systems, and cloud products.

Live site: [pallavijain.vercel.app](https://pallavijain.vercel.app)

## Highlights

- Professional profile, contact links, technical skills, and leadership experience
- Selected projects including RecallOps, Multi-Step Research Agent, Sanchit, CommitVault, CivicBounty, CoverFi, and Anti-Prod
- Responsive project and experience pages
- Live links and source repositories where publicly available
- Blog section ready for future posts

## Built with

- React 19
- Vite
- Tailwind CSS
- React Router
- Vercel Analytics

## Run locally

Requirements: Node.js and npm.

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```

Preview the production build with:

```bash
npm run preview
```

## Project structure

```text
src/
  components/    Shared layout and navigation
  data/          Portfolio content
  pages/         Home, projects, and experience pages
public/          Static assets and resume
```
