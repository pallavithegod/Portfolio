# Project screenshots

Add a screenshot for each project in this folder, using its project slug as the filename. For example:

- `ima-agent.png` for IMA (Incident Memory Agent)
- `research-agent.png` for Multi-Step Research Agent
- `sanchit.png` for Sanchit

The project list and each project detail page automatically show the matching image. Until a screenshot exists, they display `placeholder.svg`. Screenshots appear only on project pages, never on the home page.

Recommended export: 1600 × 900 pixels, compressed PNG or WebP, sized to keep each image lightweight while preserving readable interface text.
